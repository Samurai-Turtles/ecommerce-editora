# Ecommerce Editora

Repositório do projeto da disciplina "Programação para a Web I".

## Como executar

Certifique-se de que você tem o Node v18+ instalado em sua máquina. Após clonar o repositório, execute os comandos abaixo:

```bash
npm install
npm run dev
```

A aplicação estará acessível em `http://localhost:5173/products`.
